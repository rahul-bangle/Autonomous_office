# REQUIREMENTS

## Phase 1: Dashboard Shell & Core Aesthetics (REQ-1-x)
- **REQ-1.1**: The main shell must use a 3-column/sidebar layout as seen in the Origin Command screenshots.
- **REQ-1.2**: Navigation icons must include: Command Center (Home), Team Office (Users), Project Analytics (Graph), Roadmap (Calendar), Task Board (Checklist), Backlog (Archive).
- **REQ-1.3**: Global glassmorphism theme must be established in `index.css` (blur, subtle borders, dark overlays).
- **REQ-1.4**: Mobile responsiveness must be maintained (drawer-style sidebar).

## Phase 2: Live Activity Feed (REQ-2-x)
- **REQ-2.1**: A "Live Activity" window must display real-time logs from the CEO and agents.
- **REQ-2.2**: Status badges for agents must remain visible in the sidebar.
